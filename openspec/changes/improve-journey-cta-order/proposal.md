# Proposal: 導線観測スターターのCTA順序改善

## Why

2026-06-01以降のGA4実測値では、「導線観測スターター」のスクロール到達イベントが50%で24件、75%で12件となり、50%減少している。これは計測対象ページの閾値間で最大の減少率である。

同ページでは29ユーザー中17ユーザーが `article_navigation` を実行しており、主要CTAより前にある「次に読む記事」がCTA到達前の遷移先になっている可能性がある。観測事実と仮説を区別しつつ、主要CTAを先、関連記事を後に並べ、CTA体験後も記事回遊できる構造へ改善する。

## What Changes

- `products/journey-kit.html` のVariant A主要CTAを「次に読む記事」より前へ移動する。
- 関連記事をCTA後の共通セクションとして表示する。
- CTAと関連記事のイベント名・パラメータ・遷移先は変更しない。
- 変更前後をVariant A、1440×1200 viewport、`article.prose` の同一範囲で撮影する。
- GA4基準値と改修後に比較する指標を検証記録へ残す。

## Impact

- 公開サイトの商品詳細ページ1件のHTML構造が変わる。
- GA4イベント契約、Consent Mode、A/B割り当て、リンク先は変わらない。
- 比較スクリーンショットを `docs/screenshots/journey-cta-order/` に追加する。

## Approval

- 2026-08-15、ユーザーがGA4分析で特定した箇所のサイト反映と、修正前後のスクリーンショット保存を依頼した。
- 2026-08-15、ユーザーがOpenSpec成果物を確認し、実装を明示承認した。
