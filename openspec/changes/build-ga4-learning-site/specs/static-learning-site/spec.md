## Purpose

GA4学習者が架空のEC・記事サイトをスマートフォンとPCで回遊し、典型的なユーザー行動を安全かつ再現可能に試せる静的サイト体験を定義する。

## ADDED Requirements

### Requirement: 学習目的と対象ユーザー
サイトは、GA4初学者、Web制作初学者、アクセス解析を学び直す担当者が、画面上の行動と計測イベントを対応付けて学ぶための教材でなければならない（SHALL）。各ページは架空データのみを使用し、実在商品の販売や問い合わせ受付を行ってはならない（MUST NOT）。

#### Scenario: 初学者がサイトを訪問する
- **WHEN** ユーザーがトップページを開く
- **THEN** サイトが学習用デモであることと、試せる主要行動が表示される

### Requirement: ページ構成
サイトは最低限、トップ、商品一覧、商品詳細、記事一覧、記事詳細、問い合わせ完了の6種類のページを提供しなければならない（SHALL）。商品詳細と記事詳細は、異なる項目を比較できるよう各2ページ以上用意しなければならない（SHALL）。

#### Scenario: 全ページ種別へ移動する
- **WHEN** ユーザーがグローバルナビゲーションおよびページ内リンクを使用する
- **THEN** 6種類すべてのページへ到達でき、現在地を理解できる見出しとページタイトルが表示される

### Requirement: 主要ユーザー導線
サイトは「トップ→商品一覧→商品詳細→問い合わせ完了」と「トップまたは商品詳細→記事一覧→記事詳細→関連記事」の導線を提供しなければならない（SHALL）。各詳細ページは一覧へ戻る導線を持たなければならない（SHALL）。

#### Scenario: 商品関心導線を完了する
- **WHEN** ユーザーがトップから商品一覧、商品詳細、主要CTAの順に操作する
- **THEN** 問い合わせ完了ページへ到達できる

#### Scenario: 記事を回遊する
- **WHEN** ユーザーが記事詳細ページの関連記事リンクを選択する
- **THEN** 別の記事詳細ページへ移動できる

### Requirement: 問い合わせ完了ページの安全性
問い合わせ完了ページは計測学習用の到達点として機能し、氏名、メールアドレス、電話番号、自由記述などの個人情報を入力または送信させてはならない（MUST NOT）。

#### Scenario: CTAから完了ページへ遷移する
- **WHEN** ユーザーが問い合わせCTAを選択する
- **THEN** 入力フォームを経由せず問い合わせ完了ページが表示され、実際の問い合わせは送信されない旨が示される

### Requirement: レスポンシブかつアクセシブルな操作
すべてのページは幅320px以上の画面で横スクロールなしに主要コンテンツを利用できなければならない（SHALL）。ナビゲーション、CTA、カード、リンクはキーボード操作と支援技術で識別可能でなければならない（SHALL）。

#### Scenario: スマートフォンで閲覧する
- **WHEN** ユーザーが幅390pxの画面で任意のページを開く
- **THEN** 本文、ナビゲーション、CTAが重ならず、拡大操作なしで読み進められる

#### Scenario: キーボードで操作する
- **WHEN** ユーザーがTabキーとEnterキーだけでページを操作する
- **THEN** 主要導線のすべてに到達でき、フォーカス位置が視覚的に分かる
