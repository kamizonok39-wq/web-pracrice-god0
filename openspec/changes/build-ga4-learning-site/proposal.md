## Why

GA4の基本的なイベント計測と分析を、実際に操作できる小規模な静的サイトで安全に学べる環境が必要である。GitHub Pagesで再現可能な教材にすることで、初心者が画面上の行動、コード上の発火条件、GA4上の結果を対応付けて理解できるようにする。

## What Changes

- 架空の商品と記事を題材にした、スマートフォン対応の静的Webサイトを新設する。
- トップ、商品一覧、商品詳細、記事一覧、記事詳細、問い合わせ完了の各ページと、ページ間の学習用導線を設ける。
- ページ閲覧、CTAクリック、記事回遊、外部リンク、スクロール率をGA4イベントとして計測可能にする。
- CTAの文言と配置を切り替え、バリエーション別の行動差を比較できる実験機能を設ける。
- 個人情報を取得しない制約、アクセシビリティ、性能、ブラウザ対応などの非機能要件を定義する。
- GA4測定IDの設定方法、デバッグ方法、GitHub Pagesへの公開手順をREADMEに記載する。
- 実装前に受け入れ条件と実装タスクを確定し、OpenSpecで検証する。

## Capabilities

### New Capabilities

- `static-learning-site`: サイトの目的、対象ユーザー、ページ構成、レスポンシブ表示、ユーザー導線を定義する。
- `ga4-event-measurement`: GA4の導入方式、イベント名、パラメータ、発火条件、プライバシー制約を定義する。
- `cta-experimentation`: CTAの文言・配置バリエーション、割り当て、比較方法を定義する。
- `static-site-operations`: GitHub Pagesへの公開、測定ID設定、ドキュメント、品質要件を定義する。

### Modified Capabilities

なし。

## Impact

- 新規の静的HTML、CSS、JavaScript、画像等のアセットが追加対象となる。
- GA4のGoogle tagを利用するが、測定IDは環境別設定として扱い、実値をリポジトリへ固定しない。
- GitHub Pagesをホスティング先とし、サーバーサイド処理、データベース、問い合わせフォームでの個人情報送信は対象外とする。
- 初心者の可読性を優先し、ビルド工程を必須としないHTML/CSS/Vanilla JavaScriptを第一候補とする。
